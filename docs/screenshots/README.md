# Screenshots

Place your screenshots here:

- `kafka-cluster-overview.png` - Kafka cluster detail view showing broker pods, listeners, and configuration
- `topic-management.png` - Topic list and detail views
- `user-management.png` - User list with ACL visualization
- `connect-management.png` - Kafka Connect cluster and connector views
- `task-management.png` - Connector task management with restart actions

## Taking Screenshots

1. Start Headlamp with the plugin loaded
2. Navigate to each section
3. Take screenshots at 1920x1080 or higher resolution
4. Save them in this directory with the names above
5. Update the README.md to reference these screenshots
